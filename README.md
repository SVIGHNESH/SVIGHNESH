## 🧠 About Me

I got hooked on backend engineering the first time I really understood what the JVM was doing - the idea that my Java code was being JIT-compiled, garbage-collected, and tuned by a runtime underneath me made me want to know how every layer worked.
Around the same time I discovered how much more a terminal could do than any GUI, and I have lived there ever since.

- 🎓 B.Tech in Computer Science & Engineering (AKTU), 2023 - Present
- ⚙️ Writing **Java** for the depth of its ecosystem, **Node.js / TypeScript** for fast event-driven backends
- 🐧 Currently learning **Linux internals**, **cloud technologies**, and sharpening my sysadmin skills
- 🤖 Exploring **AI agents and RAG pipelines** with LangGraph and FastAPI
- 🔭 Looking for a backend role where reliability and what's-actually-happening-underneath matter
